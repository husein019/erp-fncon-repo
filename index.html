Google Sheets-i FN Construction ERP Bazasına Çevirin

Google Sheets faylınızı real-vaxt rejimində layihə, anbar, podratçı və maliyyə məlumatlarını saxlayan pulsuz bulud bazasına çevirin.

1

Google Apps Script Kodunu Kopyalayın

Google Sheets faylınızda Extensions (Uzantılar) → Apps Script hissəsinə keçin. Köhnə kodu silib bu xüsusi FN Construction kopyalayın:

2

Deploy Və Web App URL Daxil Et

Apps Script Yayımlama Addımları:

  1. Sağ yuxarıda Deploy → New Deployment düyməsini sıxın.
  2. Select type → Web app seçin.
  3. Execute as: Me, Who has access: Anyone seçin.
  4. Deploy edib aldığınız Web App URL ünvanını aşağıya yapışdırın.
